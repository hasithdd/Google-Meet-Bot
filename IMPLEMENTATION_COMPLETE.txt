HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

1. Install Dependencies:
   pip install livekit livekit-agents livekit-plugins-openai

2. Configure (add to .env):
   LIVEKIT_URL=wss://your-server.livekit.cloud
   LIVEKIT_API_KEY=your_key
   LIVEKIT_API_SECRET=your_secret
   OPENAI_API_KEY=your_openai_key

3. Run Bot (Terminal 1):
   google-meet-bot --meet-link "https://meet.google.com/xxx" --livekit

4. Start Agent (Terminal 2):
   python -m google_meet_bot.livekit_worker

5. The AI assistant joins and can interact with meeting participants!
